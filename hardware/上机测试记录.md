## 0. 三条禁令（没限位之前）

| 命令 | 为什么不能发 |
|---|---|
| `H` 回零 | `HOME_SEEK` 是无限向下走，PB12 常高不触发 → 一直顶到机械底丢步，**60 秒后**才报 `ERR 9` |
| `Z mm` | 没回零 → 直接 `ERR 5`，白发。而且 `s_pos` 没基准，数值全是假的 |
| `P x y z` | 同上，`ERR 5` |

`L` 可以发，但现在应该恒回 `LIM 0`（PB12 内部上拉、黑线悬空）。回 `LIM 1` 才是异常（PB12 被短路 / 配置错）。

## 1. 上电基线（1 条硬判据）

发 `S`，预期：

```
POS 35 0 0 85 0
```

推算过程：大臂 1485μs → 舵机角 90° → θ1 = 0；小臂 2460μs → 舵机角 180° → θ2 = −180；
FK：x = 170 + 135·cos(−180) = **35**，y = 0；腕转 1454μs → 85°；夹爪状态 0。

| 实际 | 结论 |
|---|---|
| `POS 35 0 0 85 0` | ✔ 回正到位、标定表生效 |
| x 不是 35 但 y=0 | 大臂没走准 / `THETA1_HOME_DEG` 要改 |
| 腕转不是 85 | 腕转斜坡没走完，或 PB8 虚接（重插） |
| 回 `OK` 但四路舵机全松 | 电源（量红线对棕线 5~6V） |

## 2. 四个舵机（重标前四件）

## 4. Z 轴（唯一能验的手段 = `T` 相对走）

★ `T` 命令**不检查软上限、不检查下限**，`±200mm` 内随便走，全靠眼睛。先小步试方向。

| # | 发 | 预期 |
|---|---|---|
| 1 | `E 1` | 手拧联轴器："紧但大力能拧动" = 半流锁轴正确；硬邦邦 = 全流；跟断电一样松 = 没锁上 |
| 2 | `E 0` | ★ **手扶住滑块**再发，松轴后滑块可能被自重带着下滑 |
| 3 | `T 5 2000` | 看滑块动**向上**还是向下，动 5mm（约 1s） |
| 4 | `T -5 2000` | 反向 5mm 回原位。两个方向都通 = 方向对、没丢步 |
| 5 | `T 20 8000` | 20mm/s，声音干脆不闷。闷/发抖 = 电流小或机械卡 |
| 6 | `S` | Z 位是上电累计值（无基准），只看变化量对不对 |

`T` 之后 `Z`/`P` 依然 `ERR 5`——`s_pos` 没有零点，这是正常的。

## 5. 断电重启（重标第五件）
