# 机械臂整套接线核对表

> 11-19 建，装配后逐条核对用。每条带 ☐，核完打勾。
> 万用表用法见底部"排查速查"。芯片引脚号一律指**核心板 40P 排针**（脚号见 `软件设计\09-核心板引脚对照.md`）。

---

## 1. 四个舵机信号线（橙/黄线 → 核心板）

| ☐ | 舵机 | 核心板引脚 | 脚号 | 通道 | K 命令 id |
|---|---|---|---|---|---|
| ☐ | 大臂 | PA0 | **25** | TIM2_CH1 | 0 |
| ☐ | 小臂 | PA1 | **26** | TIM2_CH2 | 1 |
| ☐ | 腕转 | PB8 | **16** | TIM4_CH3 | 2 |
| ☐ | 夹爪 | PB6 | **14** | TIM4_CH1 | 3 |

- ☐ 每根信号线的**另一端**插在舵机三线插头的**信号针**上（MG996R 线序常见棕红橙/黄：棕=GND、红=VCC、橙/黄=信号，以实测为准，别靠颜色背）
- ☐ **PB8（脚 16）的杜邦头重点压紧**——11-17 虚接就是这个头，症状是"回 OK 但舵机完全松"
- ☐ 数脚号时确认没数错排：PB6/PB7/PB8 在同一侧，PB7（脚 15）是空脚，插错到 15 上毫无反应

**核对方法**：发 `W 90`，万用表直流档量信号线对 GND，应读 **0.23~0.25V**（平均电压 = 3.3 × 脉宽/20ms）。读 0 = 线断/虚接；读 3.3 = CCR 没写进。

## 2. 舵机电源（降压模块双路）

| ☐ | 路 | 供电对象（红线） | 设定电压 | 滤波电容 |
|---|---|---|---|---|
| ☐ | CH1 | 大臂 + 小臂 红线 | **6.0V** | 并 2200μF/16V |
| ☐ | CH2 | 腕转 + 夹爪 红线 | **5~6V** | — |

- ☐ 降压模块**输入端**接 24V（模块只能降压不能升压，24V 从输入进）
- ☐ 所有舵机**棕线（GND）**汇到 GND，最终与 24V 负极、STM32 GND **共地**
- ☐ CH1/CH2 输出电压用万用表复核：低于 4.8V 舵机带不动（表现为不动也不锁轴）

**核对方法**：发 `C 0` 夹爪动 = CH2 供电正常；发 `M 90 0` 大臂动 = CH1 供电正常。

## 3. 步进驱动器（TB6600 类，端子从上往下 1~12）

### 3.1 控制信号（共阳接 3.3V，★ 不能接 5V）

| ☐ | 核心板 | 驱动器端子 | 功能 |
|---|---|---|---|
| ☐ | 脚 5（PA8） | **端子 5 PUL−** | TIM1_CH1 脉冲（R7 已拆，PA8 空载给光耦） |
| ☐ | 脚 17（PB9） | **端子 3 DIR−** | 方向 GPIO |
| ☐ | 脚 3（PB14） | **端子 1 ENA−** | 使能 GPIO（低=脱机松轴，高=锁轴） |
| ☐ | 脚 20（3.3V） | **端子 2 / 4 / 6**（ENA+ / DIR+ / PUL+）三根并联 | 共阳 |

- ☐ **PA8 上的 R7 已拆**（LED1 限流 330Ω），LED1 不亮是正常现象，电流还给光耦

### 3.2 电源与电机（★ 端子接反会烧板）

| ☐ | 从 | 到端子 | 说明 |
|---|---|---|---|
| ☐ | 24V+ | **端子 12 VCC** | 并 470μF/50V |
| ☐ | 24V− | **端子 11 GND** | ★ **必须与 STM32 GND 共地**（脚 19/39/40 任一 → 24V 负极），不共地电机左右摆不转但软件计数正常 |
| ☐ | 电机红 | **端子 10 A+** | 实测分相：红黑 = A 相（3.6Ω） |
| ☐ | 电机黑 | **端子 9 A−** | |
| ☐ | 电机蓝 | **端子 8 B+** | 实测分相：蓝绿 = B 相（3.6Ω） |
| ☐ | 电机绿 | **端子 7 B−** | ★ 商家配色图是错的，以上为实测 |

- ☐ 拨码 `0 1 0 1 0 1` = **8 细分 1600 脉冲/转 + 1.0A**（从 SW1 到 SW6）
- ☐ 脉冲当量：导程 4mm ÷ 1600 = **0.0025mm/脉冲**

**核对方法**：发 `E 1` 锁轴（手拧轴"紧但大力能拧动"= 半流锁轴正确）；发 `T 20 2000` 走 20mm，卷尺量误差。

## 4. 限位传感器（SN04-N 仿制，等分压电阻到货）

| ☐ | 线 | 接到 | 说明 |
|---|---|---|---|
| ☐ | 棕 | 24V+ | 供电 10~30V |
| ☐ | 蓝 | 24V−（GND） | |
| ☐ | 黑 | **75k（丝印 7502）→ 分压点 → 10k → GND**；**分压点 → PB12（脚 1）** | 仿制品未触发常驻 24V，必须分压，直连烧脚 |

- ☐ 分压点电压**先量后接**：未触发 2.4~2.7V、触发接近 0V 才允许接 PB12
- ☐ 传感器**检测面在侧面（正前方）**，不在轴向端面——轴向那颗是 LED 指示灯
- ☐ 装在滑台侧面凹槽，水平对准滑块上的铁指针，间隙 3~4mm（磁铁先吸一下确认指针是铁）
- ☐ 逻辑：未触发 = 高 = `LIM 0`；触发 = 低 = `LIM 1`，固件不用改

**核对方法**：接好后发 `L`，铁件对着**探头正前方**靠近/拿开，`LIM` 应 0→1 切换。

## 5. STM32 供电与共地

| ☐ | 项 | 说明 |
|---|---|---|
| ☐ | 核心板由底板 USB 供电 | **不插核心板 Type-C**，两个 AMS1117 会打架 |
| ☐ | 24V 负极 → 驱动器 GND（端子 11） → **STM32 GND（脚 19/39/40 任一）** | ★ 三点共地，缺一不可 |
| ☐ | 串口不接线 | 底板自带 CH340K，插 USB 即是（口号会变，`arm_teacher.py` 选 CH340K） |

## 6. 排查速查（症状 → 先查什么）

| 症状 | 先查 |
|---|---|
| 舵机完全松不锁轴 | 电源（红线对棕线 5~6V？）→ 电源反接（红线/棕线分别对地量）→ 信号虚接（重插） |
| 发命令回 OK 但舵机不动 | 量信号线平均电压（见 1）→ 量电源 → 互换信号线切"舵机坏 vs 通道坏" |
| 舵机持续嗡嗡发热 | **静差堵转**：摸温度确认，检查是不是被停在了非安全位（夹爪只有 1020/1580 安全） |
| 步进电机左右摆不转但软件计数正常 | **共地**（三点共地缺了哪个）→ A/B 相是否按实测接 |
| 步进丢步、走不准 | 频率太高（>8000Hz 发虚）→ 电流小 → 机械卡 |
| 上电电机自己哒哒哒慢爬 | CCR 顺序 bug（已修，若复现查 `step_init` 是否被改回去） |
| 上电电机"哒哒"自己爬没了但臂抽一下 | 正常（上电回正第一下，位置未知没法避免） |
