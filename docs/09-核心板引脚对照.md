## 三、H1 ~ H5 分别是什么（★ 已按主人补的原理图截图修正）

| 编号 | 类型 | 引出什么 | 对机械臂有用吗 |
|---|---|---|---|
| **H1** | 4P 排针 | `1=3V3` `2=WIFI_TXD` `3=WIFI_RXD` `4=GND` | **只可能拿 3V3/GND**，但核心板脚 20/38 已有，不需要 |
| **H2** | 4P 排母 | **OLED 接口**：`1=SDA` `2=SCK`（3、4 接 3V3/GND，旁有 C9 100nF 去耦） | **OLED 没插 → PB6/PB7 干净可用** ✔ |
| **H3** | 6P 跳线 | **NB-IOT / WIFI 通道选择**：`1=IOT_RXD` `2=IOT_TXD` `3=RXD2` `4=TXD2` `5=WIFI_RXD` `6=WIFI_TXD` | 不用（我们不用 USART2） |
| **H5** | 10P 排针 | **NB-IOT 模块座**：`5=IOT_TXD` `7=IOT_RXD` `9=VCC5V`，其余打叉不接 | 不用 |

**H3 的跳线逻辑（了解一下就行）：**

```
插 1-2 + 3-4  →  PA2/PA3 接到 NB-IOT 的 IOT_RXD/IOT_TXD
插 3-4 + 5-6  →  PA2/PA3 接到 WIFI 的 WIFI_RXD/WIFI_TXD
```

**不管插哪一组，占的都是 PA2/PA3（USART2），我们完全不用这两个脚，所以无所谓。**

**★ H2 是 OLED 接口这一点很重要：**

```
H2 的 1/2 脚直接连 SDA(PB7) / SCK(PB6)
原理图上没有上拉电阻
→ 没插屏时，PB6/PB7 是纯悬空
→ 夹爪 PWM 用 PB6 完全安全 ✔
```

**结论：四个排针全都不用管，直接从核心板 40P 排针取电取地。**

## 三之二、核心板两侧的 HDR1 / HDR2

核心板把 40 个脚分到两侧的两个 20P 排针上：

| 排针 | 位置 | 对应 U1 脚号 | 排列方向 |
|---|---|---|---|
| **HDR2** | 左侧 | **1 ~ 20** | 从上往下（1 在最上） |
| **HDR1** | 右侧 | **21 ~ 40** | 从下往上（21 在最下） |

**HDR2（左，1~20）从上到下：**

```
PB12  PB13  PB14  PB15  PA8  PA9  PA10  PA11  PA12  PA15
PB3   PB4   PB5   PB6   PB7  PB8  PB9   VCC5V GND   3V3
```

**HDR1（右，21~40）从下到上：**

```
VBAT  PC13  PC14  PC15  PA0  PA1  PA2  PA3  PA4  PA5
PA6   PA7   PB0   PB1   PB10 PB11 RESET 3V3  GND  GND
```

**★ 接线时看板子上的白色丝印，比数脚号可靠。** 两侧排针的脚号是从板子内侧往外印的。

## 四、SW1 是电源开关，必须闭合

`SW1 = PS-5850A-6PL`，接在 `VIN_5V → VCC5V` 之间，**是整块底板的电源总开关**。

```
底板 USB-C → F1(0.5A 自恢复保险) → VIN_5V ─┬─→ CH340K 的 VCC（不受 SW1 影响）
                                            │
                                            └─→ SW1 → VCC5V → AMS1117 → 3V3 → 核心板
```

**所以：**

| SW1 状态 | 后果 |
|---|---|
| **闭合（ON）** | 底板供电，核心板从底板 3V3 取电，正常 |
| 断开（OFF） | 只有 CH340 有电，**核心板没电，J-Link 连不上（VTref=0）** |

**它是锁定式开关，不是按钮** —— 按一下锁定在 ON，再按一下弹起 OFF。

## 五、★ 只插一根 USB，别插两根

底板和核心板**各自都有一个 AMS1117 输出 3.3V**，两个 3V3 网络在板上是连通的。

```
底板 USB-C → AMS1117 → 3V3 ─┐
                             ├─ 同一根 3V3 网络
核心板 Type-C → AMS1117 → 3V3 ┘
```

**两个稳压器同时输出会互相灌电流，轻则发热，重则烧其中一个。**

**推荐接法（只用底板 USB）：**

```
✔ 插：底板的 USB-C（给 CH340 转串口 + 经 SW1 给整板供电）
✔ 拨：SW1 = ON
✘ 不插：核心板的 Type-C

J-Link 接 SWD（PA13/PA14/GND + 3.3V），正常烧录
```

**这样一根线搞定供电和串口，最干净。**

## 六、PA8 上那颗 LED 要不要拆

**先别拆。** PA8 发脉冲时 LED1 会以脉冲频率闪，人眼看到的是"常亮但偏暗"。

电流账：

```
光耦 7.8mA + LED 4.2mA = 12mA
PA8 单脚能力 20mA
```

**还有 8mA 余量，能用。**

**但如果遇到高速丢步（12kHz 以上），第一个怀疑对象就是这里。** 拆掉 `R7`（330Ω）就能把 4.2mA 还回去。

---

## 七、PB12 的按键会不会干扰限位

**不会，反而是好事。**

```
PB12 上：R1(10kΩ) 上拉到 3V3，SW2 按键到 GND
限位传感器（NPN 开漏）：不触发时悬空，触发时拉到 0V
```

**两者并联，都是"拉低有效"，完全兼容。**

- 传感器不触发 + 按键不按 → 10k 上拉 → 高电平 ✓
- 传感器触发 → 拉低 → 下降沿 ✓
- **误按 SW2 → 也拉低 → 会误触发回零，测试时手别碰** ⚠️

CubeMX 里配了内部上拉，和外部 10k 并联约 8k，没问题。

| 项 | 空白板 | 现在这块（焊好的） |
|---|---|---|
| PB6/PB7 | 完全空 | **OLED 焊盘有，但没插屏 → 可用** ✔ |
| PA8 | 完全空 | 有 LED1，会闪但不影响 ✔ |
| PB12 | 完全空 | 有 SW2 按键，别按就行 ✔ |
| 串口 | 要外接 USB-TTL | **底板自带 CH340K** ✔ |
| 供电 | 只能核心板 USB | 底板 USB 一根搞定 ✔ |
| LoRa/ESP8266 | 没有 | 焊了，但占的脚我们都不用 ✔ |

**结论：这块板比空白板好用，直接用。**
