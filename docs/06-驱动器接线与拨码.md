# 06 · 步进驱动器接线与拨码

> 依据：驱动器外壳丝印 + 实物拨码照片 + 电机铭牌（主人 11-07 拍照）
> 驱动器外壳只有 `Microstep Driver` + `DC:9~42VDC`，另有一张 `5780` 贴纸（是批次号不是型号），按通用 TB6600 类两相混合式驱动器对待
> 电机：`ATOMSTACK 42SHDC1067Z-15B`，1.0A / 6.7Ω
> 电源：`AC/DC ADAPTOR MODEL 2450`，OUTPUT **DC 24V 5A** ✔
> 更新时间：2026-11-07

---

## 一、端子定义（★ 从上到下，别接错）

外壳右侧接线端子，**从上往下 12 个孔**：

| 位置 | 丝印 | 接到哪 | 说明 |
|---|---|---|---|
| 1 | `ENA−` | STM32 PB14（共阳时） | 使能，低有效 |
| 2 | `ENA+` | 3.3V（共阳时） | |
| 3 | `DIR−` | STM32 PB9 | 方向 |
| 4 | `DIR+` | 3.3V | |
| 5 | `PUL−` | STM32 PA8 | 脉冲 |
| 6 | `PUL+` | 3.3V | |
| 7 | `B−` | 电机 B 相 | **蓝线**（常见配色） |
| 8 | `B+` | 电机 B 相 | **黄线** |
| 9 | `A−` | 电机 A 相 | **绿线** |
| 10 | `A+` | 电机 A 相 | **红线** |
| 11 | `GND` | 24V 电源 **负极** | |
| 12 | `VCC` | 24V 电源 **正极** | |

### ★★ 两个致命位置

1. **`VCC`/`GND` 在最下面，`ENA−` 在最上面。** 接反一次 24V 直接灌进 STM32，整块板报废。**上电前用万用表量一遍**：VCC 对 GND 应该是 24V，PUL+ 对 GND 应该是 3.3V。
2. **`B−/B+/A−/A+` 顺序是 B 在上、A 在下**，不是 A 在上。两相接反电机会反转（不影响使用），**单相反了会原地抖不转**。分不清就随便接，抖就换一相对调。

## 二、拨码开关：SW1～SW6

板子顶部丝印 `SW6 SW5 SW4 SW3 SW2 SW1`（**从右往左是 SW1→SW6**，注意方向）。

- **SW1 / SW2 / SW3** → 管细分（Microstep）
- **SW4 / SW5 / SW6** → 管电流（Current）

> ★ 实物上 `ON` 字样在哪一侧，拨过去就是 ON。拍照确认一次，不同批次方向会反。

### 2.1 细分表（SW1 SW2 SW3）

| 细分 | 脉冲/转 | SW1 | SW2 | SW3 |
|---|---|---|---|---|
| NC（不用） | NC | ON | ON | ON |
| 1 | 200 | ON | ON | OFF |
| 2/A | 400 | ON | OFF | ON |
| 2/B | 400 | OFF | ON | ON |
| 4 | 800 | ON | OFF | OFF |
| **8** | **1600** | **OFF** | **ON** | **OFF** |
| 16 | 3200 | OFF | OFF | ON |
| 32 | 6400 | OFF | OFF | OFF |

**我们要的是第 6 行：`SW1=OFF, SW2=ON, SW3=OFF`** → 1600 脉冲/转 → 脉冲当量 `4mm ÷ 1600 = 0.0025mm`。

> ★ **第一行 `NC / ON ON ON` 是"不细分"，电机基本不转。** 全拨 ON 会让人以为驱动器坏了。
>
> ★ **最后一行 `32 细分 / 全 OFF`** 很容易误设成这个（觉得"全 OFF 最干净"），那样脉冲当量变成 0.000625mm，所有 Z 坐标差 4 倍。

### 2.2 电流表（SW4 SW5 SW6）

外壳印的是**有效值 / 峰值**两列：

| 有效电流 | 峰值电流 | SW4 | SW5 | SW6 |
|---|---|---|---|---|
| **0.5A** | 0.7A | **ON** | **ON** | **ON** |
| 1.0A | 1.2A | ON | OFF | ON |
| 1.5A | 1.7A | ON | ON | OFF |
| 2.0A | 2.2A | ON | OFF | OFF |
| 2.5A | 2.7A | OFF | ON | ON |
| 2.8A | 2.9A | OFF | OFF | ON |
| 3.0A | 3.2A | OFF | ON | OFF |
| 3.5A | 4.0A | OFF | OFF | OFF |

**出厂 0.5A = 三个全 ON。**

### 2.3 电流到底设多少（★ 已确认电机型号）

**电机：`ATOMSTACK 42SHDC1067Z-15B`（LOT NO. 210824）**

型号里的 `1067` 是厂家编码，表示 **1.0A 相电流 / 6.7Ω 相电阻**。ATOMSTACK 是激光雕刻机品牌，这批电机就是给雕刻机用的，典型参数：

| 项 | 值 |
|---|---|
| 步距角 | 1.8°（200 步/转） |
| **额定相电流** | **1.0 A** |
| 相电阻 | 6.7 Ω |
| 保持扭矩 | 约 0.32 N·m（≈ 3.2 kg·cm） |
| 机身长度 | 约 34～40mm |

**扭矩账：**

```
垂直负载：机械臂 300g + 夹板约 200g + 滑块约 100g ≈ 0.6kg
T8 丝杆导程 4mm，梯形丝杆效率约 0.35

所需扭矩 = 0.6 × 9.8 × 0.004 / (2π × 0.35) = 0.011 N·m = 0.11 kg·cm
```

| 驱动器设的电流 | 电机能出扭矩 | 相对需求 |
|---|---|---|
| 0.5A（现在） | 约 1.6 kg·cm | 14 倍 |
| **1.0A（建议）** | **约 3.2 kg·cm** | **29 倍** |

**结论：0.5A 物理上够用，但建议调到 1.0A。** 理由：

- 0.5A 时加速段扭矩余量只有一半，起步和换向容易丢步
- 1.0A 是电机铭牌额定值，**不是超载**，正常发热在 80°C 以内
- 卖家说的"不要调大"是针对老式大电流 42 步进（1.7A），这只电机本来就只有 1.0A

**改法：`SW4=ON, SW5=OFF, SW6=ON`（把 SW5 从 ON 拨到 OFF）。**

> **丝杆和滑块才是真瓶颈，不是电机。** 滑块只有 1cm 宽，额定力矩负载 1～2 kg·cm。电流开到 3.5A 那种，先坏的肯定是丝杆螺母。

### 2.4 实物拨码（已确认，11-07 18:38）

主人读的实际位置：**上 上 下 下 上 下**（从 SW1 到 SW6）。左侧 `ON ↓` 表示朝下是 ON：

| 位置 | 实物 | 判断 | 含义 |
|---|---|---|---|
| SW1 | 上 | **OFF** | |
| SW2 | 上 | **OFF** | |
| SW3 | 下 | **ON** | 细分 |
| SW4 | 下 | **ON** | |
| SW5 | 上 | **OFF** | |
| SW6 | 下 | **ON** | 电流 |

查表：

- **细分 = `OFF OFF ON` = 16 细分 = 3200 脉冲/转**（不是原计划的 1600）
- **电流 = `ON OFF ON` = 1.0A / 峰值 1.2A** ✔ **正好是电机的铭牌额定值，不用动**

**所以电流这一项不用管，只有细分要改。**

### 2.5 ★ 只需要改两个开关

| 拨码 | 现在 | **改成** | 动作 |
|---|---|---|---|
| SW1 | 上（OFF） | 上（OFF） | 不动 |
| SW2 | 上（OFF） | **下（ON）** | **拨一下** |
| SW3 | 下（ON） | **上（OFF）** | **拨一下** |
| SW4 | 下（ON） | 下（ON） | 不动 |
| SW5 | 上（OFF） | 上（OFF） | 不动 |
| SW6 | 下（ON） | 下（ON） | 不动 |

**最终：上 下 上 下 上 下**（8 细分 = 1600 脉冲/转 + 1.0A）

**为什么改：**

| 项 | 16 细分（现在） | **8 细分（改后）** |
|---|---|---|
| 每转脉冲 | 3200 | **1600** |
| 脉冲当量 | 0.00125mm | **0.0025mm** |
| 20mm/s 时脉冲频率 | 16 kHz | **8 kHz** |
| 30mm/s 时脉冲频率 | 24 kHz | **12 kHz** |

1. T8 丝杆本身重复精度只有 0.02～0.05mm，0.00125mm 的细分精度纯属浪费
2. 同样速度下脉冲频率翻倍，3.3V 弱驱动光耦在 20kHz 已经接近极限，10kHz 稳得多
3. `step.h` 里的 `STEP_MM_PER_PULSE = 0.0025f` 和 `STEP_F_MAX_LIMIT = 12000` 一个字都不用改

> **如果不想改拨码也能用**，那 `step.h` 要同步改成 `0.00125f` 和 `24000`。要改的地方一样多，但高速时更吃力，不划算。

### 2.6 拨码随时能改（不用怕）

**DIP 开关就是给人拨的，不是一次性的。** 用指甲或小一字螺丝刀拨就行：

1. **断电拨**（带电拨一般也不会烧，但驱动器可能瞬间收到乱码信号，让电机抖一下）
2. 拨完用手按一下确认卡到位，别停在中间
3. **拨码一改，Z 轴坐标全变**：因为一个脉冲对应的距离变了，必须重新回零

> 拨码开关的寿命一般 1000～5000 次，调试期间改十几次完全没问题。

## 三、共阳接法（推荐）

```
                  3.3V ──┬──────┬──────┐
                         │      │      │
                    ENA+    DIR+    PUL+
                         │      │      │
                    ENA−    DIR−    PUL−
                         │      │      │
                     PB14     PB9     PA8
                    （拉低=使能）（拉低=一个方向）（拉低=发脉冲）
```

**为什么共阳接 3.3V，不接 5V：**

驱动器输入是光耦 LED + 内部限流电阻。共阳接法下，MCU 输出**高电平**时两端压差是：

| 共阳接 | MCU 输出高时压差 | 后果 |
|---|---|---|
| **3.3V** | 3.3 − 3.3 = **0V** | 光耦完全关断 ✔ |
| 5V | 5 − 3.3 = **1.7V** | 光耦半导通，脉冲乱发、方向乱跳 ✘ |

**共阳接 3.3V 时 MCU 是灌电流**（sink）：光耦 LED 压降约 1.2V，内部若串 270Ω，电流 = (3.3−1.2)/270 ≈ **7.8mA**。PA8 单脚能灌 20mA，够。

**★ 但 7.8mA 是估算。** 有些批次的驱动器内部按 5V 设计（串 470Ω），3.3V 只有 4.5mA，可能点不亮光耦。**装好后必须实测**：

```
上电 → 发 10 个脉冲 → 电机应该"哒"一声转一点点
没反应 = 光耦没导通，走下面的兜底方案
```

### 3.1 兜底方案（3.3V 点不亮时）

| 方案 | 做法 | 成本 |
|---|---|---|
| **A. 加 74HCT245** | 3.3V → 5V 电平转换，共阳接 5V | 3 元，要焊 |
| **B. 串二极管** | MCU 脚 → 1N4148 阳极，阴极 → PUL−/DIR−/ENA−，共阳接 5V。MCU 高电平时二极管反偏截止 | 3 个二极管 |
| **C. 用 5V 单片机** | 换 STC/Arduino，不现实 | — |

**推荐 B**：三颗 1N4148，一个方向一个，成本几毛。原理是"开漏模拟"——MCU 只能把线拉低，不能推高，正好符合共阳光耦的需要。

## 四、上电检查顺序（★ 严格按这个来）

```
① 不接电机、不接 STM32，只接 24V 到 VCC/GND
   → PWR 灯亮（绿），不报警
   → 万用表量 PUL+ 对 GND：应该是 0V（还没接 3.3V）

② 接 3.3V 到 PUL+/DIR+/ENA+，仍不接 MCU
   → 万用表量 PUL+ 对 GND：3.3V ✔
   → 量 PUL− 对 GND：也应该是 3.3V（因为没有拉低）

③ 把 PUL− 用镊子短接到 GND
   → 应该听到电机（如果接了）"哒"一声
   → 没接电机时，PWR/ALARM 灯不变

④ 接电机线（A+/A−/B+/B−），用手转电机轴
   → 拧不动（驱动器通电时默认锁轴）✔
   → 能轻松转 = 使能没生效，检查 ENA

⑤ 接 STM32 的 PA8/PB9/PB14，烧固件
```

## 五、PWR/ALARM 灯的含义

| 灯 | 含义 |
|---|---|
| 绿灯常亮 | 电源正常 |
| 绿灯闪 | 通常还是正常（有些型号是心跳） |
| **红灯亮** | 报警：过流 / 过压 / 短路 / 电机线接错 |
| 红绿交替 | 缺相（A/B 其中一组没接好） |

**红灯一亮立刻断电。** 常见原因是电机线接错（A 相和 B 相混了）或者电源电压超过 42V。

## 六、高速时的注意事项

驱动器光耦的响应速度决定最高脉冲频率。这类驱动器：

- 光耦 PC817：最高约 **50 kHz**（但高速时波形失真）
- 高速光耦 6N137：可到 **500 kHz**

我们的需求：

| 速度 | 脉冲频率 |
|---|---|
| 20 mm/s | 8 kHz |
| 30 mm/s | 12 kHz |

**8～12 kHz 完全在安全区**，不用管光耦速度。

**但如果是 3.3V 驱动（7.8mA），高速时上升沿会变慢**，12kHz 下可能开始丢步。这就是为什么建议先实测——低速能转不代表高速能转，**验收要拉到 30mm/s 试**。
