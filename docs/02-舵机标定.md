# 02 · 舵机标定

> 这是 P0 里唯一"不需要等零件、当天能做完"的事，也是后面所有舵机代码的地基
> 更新时间：2026-11-07

---

## 一、为什么要标定

同一批 MG996R，每个的 0° / 180° 对应脉宽都不一样，能差 100～200μs。要是代码里全部按"1500 = 中位、1000 = 0°、2000 = 180°"硬写，后果是：

- 三个关节的零位各偏几度，逆运动学算出来的坐标全错
- 某个舵机走到"170°"时其实已经顶到内部限位，**嗡嗡响、发烫、烧电机**

所以每个舵机都得单独测一张表。

## 二、厂家给的参数（11-07 商家资料 + 说明书）

### 2.1 PWM 对应关系（两个资料只是坐标零点不同，本质一致）

| 脉宽 | 商家图（-90～+90 坐标） | 说明书（0～180 坐标） | 我的代码（0～180 坐标） |
|---|---|---|---|
| 0.5ms | −90° | 0° | 0 |
| 1.0ms | −45° | 45° | 45 |
| **1.5ms** | **0°（中位）** | **90°（中位）** | **90（中位）** |
| 2.0ms | 45° | 135° | 135 |
| 2.5ms | 90° | 180° | 180 |

**结论：`servo.c` 里 `us_min=500 / us_max=2500`、中位 1500 的映射是对的，不用改。** 代码里的"指令角 0～180"就是说明书那套坐标。

### 2.2 其他实测参数

| 项 | 值 | 对我们的意义 |
|---|---|---|
| 类型 | **数字舵机** | 死区小、响应快，比模拟舵机好控 |
| **死区** | **4μs** | = 0.36°。这是能分辨的最小角度，比预想的好 |
| 空载电流 | **100mA** | 三个舵机空载才 300mA，5V/2A 充电器完全够 |
| 堵转电流 | 约 2.5A（MG996R 标称） | 堵转才需要大电容，正常动作不需要 |
| 速度 | 0.17s/60° @4.8V | = 353°/s，走 90° 要 0.25 秒 |
| 行程 | 最大 180° | 不能 360°，确认过了 |

### 2.3 舵机型号已确认：确实是 MG996R

实物标签（11-07 拍照）：`TIANKONGRC` / **`MG 996R`** / `DIGI HI TORQUE`

**`说明文档.txt` 那份是 MG995 的，参数不能照抄**：

| | MG995（说明书） | **MG996R（实物）** |
|---|---|---|
| 扭矩 @4.8V | 13 kg·cm | **9.4 kg·cm** |
| 扭矩 @6.0V | — | 约 11 kg·cm |
| 齿轮 | 金属铜齿 | 金属铜齿 |
| 死区 | 4μs | 4μs（同规格，可信） |
| PWM | 0.5～2.5ms / 180° | **同样**（这一类舵机通用，可信） |

**实际按 9.4 kg·cm 算余量**（比说明书少 28%）。

### 2.4 扭矩够不够（算一遍，★ 两个不同的力不能混）

很多人把"转得动"和"撑得住"当成一回事，其实是两个独立的力：

**力一：绕 Z 轴的转动扭矩（驱动臂摆动）**

```
各部件转动惯量 J = Σ m·r²
  大臂 200g @ 68mm  → 0.00092 kg·m²
  小臂舵机 55g @137mm → 0.00103
  小臂 200g @ 205mm  → 0.00840
  夹爪舵机 55g @274mm → 0.00413
  夹爪 80g @ 274mm   → 0.00601
  J ≈ 0.0205 kg·m²

0.2 秒内加速到 90°/s（1.57 rad/s） → α = 7.85 rad/s²
所需扭矩 = J × α = 0.161 N·m = 1.64 kg·cm
加上摩擦，算 3 kg·cm
```

**MG996R 9.4 kg·cm ÷ 3 = 3.1 倍余量，转动完全够。**
（因为 SCARA 是水平构型，重力垂直于运动平面，**转动时不需要对抗重力**）

**力二：压在输出轴上的悬臂弯矩（这个才是问题）**

```
各部件重量 × 到回转轴的距离：
  大臂 200g × 6.8cm  = 1.36 kg·cm
  小臂舵机 55g × 13.7cm = 0.75
  小臂 200g × 20.5cm = 4.10
  夹爪舵机 55g × 27.4cm = 1.51
  夹爪 80g × 27.4cm  = 2.19
  ────────────────────────────
  合计 ≈ 9.9 kg·cm
```

**9.9 kg·cm 的弯矩压在 5mm 输出轴上。** MG996R 厂家不标轴向承载，按同类经验，这种双滚珠轴承舵机能长期承受的径向力约 3～5kg，等效弯矩 3～5 kg·cm。

**超载约 2～3 倍。**

**表现（装好后重点观察）：**
- 臂在水平位时**明显下垂**
- 舵机持续"嗡嗡"响（在跟重力较劲）
- 用久了齿轮间隙变大、臂晃动

**★ 更要命的是滑台滑块。** 它要承受同样的 9.9 kg·cm，而滑块只有 1cm 宽、4.2cm 长。交接文档估它额定 1～2 kg·cm（这个估值偏保守，实际导轨抗倾覆能力取决于接触长度，可能到 20～40 kg·cm，**要装好实测**）。

### 2.5 缓解手段（按性价比排）

| 手段 | 效果 | 代价 |
|---|---|---|
| **降压模块 CH1 调到 6.0V** | 扭矩 9.4 → 11 kg·cm，转动余量从 3.1 倍升到 3.7 倍 | 免费，但**对弯矩没用** |
| **缩短臂长 137 → 110mm** | 弯矩降 25%，工作半径从 274 降到 220mm | 够用 |
| **减重**（夹爪换塑料、小臂打孔） | 每减 50g 末端，弯矩降约 1.4 kg·cm | 手工活 |
| 臂下垂时加托辊 | 弯矩转移到托辊，舵机只出力矩 | 结构复杂，暂时不做 |

**先按原尺寸装，装完立刻做一个测试：** 臂水平伸直，手轻按末端，看
1. 舵机有没有"嗡嗡"声（有 = 在跟重力较劲）
2. 松手后臂能不能回原位（回不去 = 齿轮已经偏载）
3. 滑块有没有倾斜/卡顿

**任何一条中招，就缩臂长。** 137mm 不是必须的，110mm 一样能演示。

> **STM32 不能吃 6V。** 两路降压必须分开：CH1（舵机）6.0V，CH2（STM32 + 摄像头）5V。

## 三、要测出哪 4 个量

| 量 | 符号 | 怎么用 |
|---|---|---|
| **中位脉宽** | `us_center` | 该舵机机械中位对应的脉宽，代码里 90° 指令角发这个 |
| **增益** | `deg_per_us` | 每 1μs 脉宽对应多少度机械转角，标准值 0.09°/μs（180°÷2000μs） |
| **安全下限** | `us_min` | 再小就顶机械限位了，不许超过 |
| **安全上限** | `us_max` | 再大就顶机械限位了，不许超过 |

**增益不用单独测两次**：`deg_per_us = (2000μs 位置的角度 − 1000μs 位置的角度) / 1000`。

## 四、阶段 A：舵机单体标定（空载，现在就能做）

**⚠️ 三个铁律：**
1. **5V 供电，绝不是 12V**（MG996R 4.8～6.6V，12V 上去直接冒烟）
2. **舵盘先不接臂**，空载转，万一超程不会把结构拧坏
3. **手不要捏舵盘**，堵转 2.5A 会把 5V 电源拉垮、把 STM32 带跑飞

### 4.1 准备

| 东西 | 说明 |
|---|---|
| 5V 电源 | 手机充电器 + 杜邦线，或降压模块 CH1。**不要从 STM32 板的 5V 取**，堵转瞬间 2.5A 会把板子拉复位 |
| 舵机测试固件 | 串口发命令调脉宽的版本，我来写 |
| 量角工具 | 手机装个"量角器 / 水平仪"APP，贴在舵盘上读 |

### 4.2 流程（每个舵机重复一遍）

```
1. 上电，默认 1500μs，等舵机停稳
2. 把手机贴在舵盘平面上，读出角度 → 记 A1500
   （读的其实是"舵盘相对某个基准的方向"，基准随便定，只要全程不变）
3. 发命令走到 1000μs，停稳，读角度 → 记 A1000
4. 发命令走到 2000μs，停稳，读角度 → 记 A2000
5. 算增益：deg_per_us = (A2000 − A1000) / 1000
6. 试探安全边界（★ 慢慢来）：
   - 从 2000 往上，每次 +50μs，听声音
   - 听到"嗡嗡"的堵转声、或者舵机壳开始发烫 → 立刻退 100μs，记作 us_max
   - 从 1000 往下同样的操作 → us_min
7. 填表
```

**第 6 步的判据（不用仪器）：**
- 正常转动：只有齿轮的"沙沙"声
- 顶到限位：**持续的"嗡嗡" + 外壳几秒内变温**
- 听到嗡嗡立刻退，别恋战

### 4.3 记录表（拿笔填，或者直接拍照发我）

| # | 装在哪 | A1500 | A1000 | A2000 | deg_per_us | us_min | us_max | 备注 |
|---|---|---|---|---|---|---|---|---|
| 0 | 大臂（底座） | 0° | −45° | +45° | 0.0933 | **520** | **2450** | 11-11 手机指南针实测 |
| 1 | 小臂 | — | — | — | 0.0942 | **550** | **2460** | 同上 |
| 2 | 腕转 | — | — | — | 0.0891 | **500** | **2520** | 绕竖直轴转夹爪朝向 |
| 3 | 夹爪 | — | — | — | — | 打开 **1020** | 闭合 **1580** | ★ 不是 ±90°，是开/合两个安全位，见下 |

**★ 夹爪的特殊标定（11-11 实测，和关节舵机不是一回事）：**

夹爪不参与逆运动学，不需要 ±90° 精度，只需要两个“不顶死”的位置。机械爪连杆到两端会顶死，舵机闭环保位静差压在卡点上 → 轻微堵转嗡嗡（约 2.5A，久了烧）。

**有效做法是先过冲、再退回 20μs：**

| 动作 | 先发 | 再退到 | 静音值 |
|---|---|---|---|
| 完全合上并轻微夹紧 | 1600 | 1580 | **1580** |
| 完全打开 | 1000 | 1020 | **1020** |

- 20μs ≈ 1.8°，在死区 4μs 之上、又小到不改变夹持效果
- ★ **不能直接发 1020**：从中间位置一步到 1020 反而会堵转，必须走“1000 → 1020”这个过程
- 1000μs 不是夹爪完全打开，但已接近；装机械爪后复测开口够不够夹 40mm 方块

> **四个都要测，没有备件了。** 编号就是代码里的 `ServoId_t`：0 大臂 / 1 小臂 / 2 腕转 / 3 夹爪。

**★ 每列到底填什么（别纠结）：**

| 表头 | 定义 | 怎么得到 |
|---|---|---|
| `A1500` / `A1000` / `A2000` | 发对应脉宽时舵盘的**角度读数**。基准自己定（比如舵盘上贴个纸箭头对准桌沿），**全程不变**就行，读的是相对值 | 手机量角器 / 纸折 45° 对比 |
| `deg_per_us` | 增益 = (A2000 − A1000) / 1000 | **代码不用这一列**。理论 0.09；实测 0.09 就说明线性度正常，偏差大说明测量或舵机有问题 |
| `us_min` / `us_max` | 机械**能安全到达**的两端对应脉宽 | 从 1000 往下 / 从 2000 往上，每次 ±50，**听到嗡嗡立刻退 100**，退回值即边界 |

**★ 常见误解：1000～2000 只有 90°，不是舵机坏了。** 标准 MG996R 是 500μs=0°、1500μs=90°、2500μs=180°，1000～2000 只是中间一半（45°～135°）。全程 180° 要发 500 和 2500，但多数舵机真实机械行程到不了标称值，那两个端点就是靠 `us_min`/`us_max` 试出来的。

**★ 代码角度是 0～180，不是 −90～+90。** `servo_deg_to_us()` 把 0～180 线性映射到 `us_min~us_max`。量角器读数只是参考，最终进代码的只有两个端点值。

**★ 实测发现（11-10，0 号大臂）：有些批次 MG996R 机械余量大。** 400～2600μs 全程扫下来**不顶死、不发热、无嗡嗡**，用“听声音定边界”的方法失效。此时：

1. 边界不能照抄 400/2600 —— 已超厂家标称 100μs，电位器接近端点非线性变大
2. 取**实测线性度最好的一对脉宽**做端点。本例 500/2500 时舵盘超过 ±90°，550/2430 才对齐 → 填 **550/2430**（行程 169°，略小于 180° 是精度换行程的代价）
3. **同批舵机脾气不同**，另外三只必须照样逐个扫，不能拿 0 号的结论套
4. 判据换成“手摸舵机本体感知振动和温升”+ 观察角度是否连续响应（不跳变 = 齿轮和电位器没打滑）

## 五、阶段 B：整机标定（装配后）

这一阶段测的是"机械"，不是舵机。

### 5.1 实测两个臂长

| 量 | 定义 | 理论值 | 实测 |
|---|---|---|---|
| `L1` | 底座回转中心 → 小臂舵机轴心 | 137mm | ? |
| `L2` | 小臂舵机轴心 → 夹爪中心 | 137mm | ? |

**怎么量：** 游标卡尺从**舵机轴心**（不是舵盘边缘）量到**下一个舵机轴心**。装舵盘有偏心，量舵盘外圈会差 2～3mm。

> 差值直接进 `kinematics.h` 的 `ARM_L1_MM` / `ARM_L2_MM`。别偷懒用 137。

### 5.2 测中位姿态（决定 `THETA1_HOME` / `THETA2_HOME`）

装配时的目标是：
- **大臂**：舵机发 1500μs，大臂指向**正前方**（工作区中心），此时 `THETA1_HOME = 0`
- **小臂**：舵机发 1500μs，小臂**相对大臂折 90°**，此时 `THETA2_HOME = 90`

但 25T 舵盘最小分度是 360°/25 = **14.4°**，装不到绝对准。所以：

```
1. 1500μs 下装上舵盘，选最接近目标的那一档花键
2. 手机量出实际偏差角 δ1、δ2（几度）
3. THETA1_HOME = δ1，THETA2_HOME = 90 + δ2
```

### 5.3 测机械干涉极限（决定 `SERVO1_MIN/MAX`、`SERVO2_MIN/MAX`）

| 关节 | 往哪转会撞 | 撞之前的脉宽 | 换算成安全边界（退 5° 余量） |
|---|---|---|---|
| 大臂 θ1 | 顺时针（往右后方） | | `SERVO1_MIN_DEG` |
| 大臂 θ1 | 逆时针（往左后方） | | `SERVO1_MAX_DEG` |
| 小臂 θ2 | 折得太厉害（两臂快贴住） | | `SERVO2_MAX_DEG` |

**为什么 θ2 只有一侧有边界**：小臂舵机 1500μs 时是折 90°，往一个方向是"伸直"（θ2 变小，到 0 是直臂，不会再撞），往另一个方向是"继续折"（θ2 变大，到 140～150° 时两臂会蹭上）。所以 θ2 只需要一个上界。

### 5.4 标定表（实际代码里只有 3 个字段）

`servo.c` 里的表：

```c
const ServoCal_t g_servo_cal[SERVO_NUM] = {
    // us_min, us_max, dir
    {   500,   2500,   1.0f },   // 0 大臂   ← 标定后把 500/2500 收紧成实测安全范围
    {   500,   2500,   1.0f },   // 1 小臂
    {   500,   2500,  -1.0f },   // 2 夹爪（装反了改 -1）
};
```

**没有 `us_center` 和 `deg_per_us` 两个字段。** 原因：MG996R 这类舵机的 `deg_per_us` 严格是 0.09（2000μs ÷ 180°），实测差异来自"端点不在 500/2500"，而不是斜率不对。所以只要测准 `us_min` / `us_max` 两个端点，中间线性插值就够了。

## 六、标定固件已经写好了

`code/User/app/app_main.c` 就是标定固件，在 PC 上跑通了协议解析（`pc_test/test_protocol.c`）。

### 6.1 串口命令（115200 8N1）

| 命令 | 作用 | 例子 |
|---|---|---|
| `K <id> <us> [ms]` | **★ 标定核心**：慢速给某路舵机脉宽（默认 2 秒走完），绕过安全夹紧。`ms=0` 直跳 | `K 0 1500` / `K 0 1000 500` |
| `W <0~180>` | 腕转单独转到某个角度 | `W 90` |
| `M <x> <y>` | 平面移动到桌面坐标 | `M 180 60` |
| `Z <mm>` | 升降到绝对高度 | `Z 80` |
| `P <x> <y> <z> [rot]` | 一次到位，rot 是可选朝向 | `P 150 150 80 90` |
| `C <0/1>` | 夹爪张开 / 闭合 | `C 1` |
| `H` | 回零 | `H` |
| `S` | 查当前位置 | `S` → `POS 137 137 0 90 1` |
| `E <0/1>` | 步进松轴 / 锁轴 | `E 0` |
| `R` | 清故障 | `R` |
| `?` | 帮助 | `?` |

**`id` 对应：0 = 大臂，1 = 小臂，2 = 腕转，3 = 夹爪。**

### 6.2 标定操作流程（用这套命令）

**★ `K` 命令现在默认 2 秒慢慢走**（固件里是 20ms 节拍的脉宽斜坡），转起来安静、看得清。嫌慢可以带第三个参数，比如 `K 0 1500 800` 是 0.8 秒；`K 0 1500 0` 是直跳。边界试探建议用默认 2 秒。

```
1. 上电，四个舵机自动回 1500μs
2. 量 0 号（大臂）当前位置的角度 → 记 A1500
3. 发 K 0 1000 → 等它慢慢转到位 → 量角度 → 记 A1000
4. 发 K 0 2000 → 量角度 → 记 A2000
5. 发 K 0 700，慢慢往下降：K 0 650、K 0 600...
   ★ 听到"嗡嗡"声（顶死了）立刻退回 100μs，那个值就是 us_min
6. 往上升：K 0 2300、K 0 2350...
   同样听到嗡嗡就退回，得到 us_max
7. 换 id=1、2、3 重复
8. 发 K 0 1500 把臂归位
```

**★ 试探边界时一次只动 50μs，别一次跳 200μs。** 5μs 是舵机死区，50μs = 4.5°，能听出声音变化。

### 6.3 PC 端串口工具

不用装任何东西，VS Code 装 `Serial Monitor` 插件，或者用 `stm32\tools\serial_monitor.py`。

用 Python 写脚本自动扫更省事：

```python
import serial, time
ser = serial.Serial('COM3', 115200, timeout=1)

def k(i, us):
    ser.write(f'K {i} {us}\n'.encode())
    return ser.readline().decode().strip()

for us in range(1500, 700, -50):     # 从 1500 往下扫到 700
    print(us, k(0, us))
    time.sleep(0.8)                  # 留时间给舵机到位和听声音
```

跑到听到嗡嗡声就按 Ctrl+C，记下上一个值。

## 七、写舵机驱动时的四个预警

1. **上电瞬间舵机会抽一下** —— CubeMX 生成的 `MX_TIM2_Init()` 里 PWM 是关着的，引脚在 `HAL_TIM_PWM_Start()` 之前是低电平，舵机把它当 0μs 的极值信号。解法：`MX_TIM2_Init()` 之后、`main()` 的 while 之前立刻 `HAL_TIM_PWM_Start()` 并先写 CCR=1500。
2. **改 CCR 不用停 PWM** —— `__HAL_TIM_SET_COMPARE()` 直接改寄存器，下一个周期就生效。别写"停—改—启"，那样每次改角度都会抖一下。
3. **TIM1 是高级定时器** —— `HAL_TIM_PWM_Stop()` 会连 MOE 一起关，重新 `Start()` 会自动开回来。但 **`HAL_TIM_PWM_Start()` 之前必须先 `MX_TIM1_Init()`**，否则 MOE 开着没输出。
4. **CCR 写 0 不等于关断** —— 在 PWM mode 1 下 CCR=0 输出恒低，光耦不导通，效果等于停发脉冲。步进停止就用这招，别用 `HAL_TIM_PWM_Stop()`（停止后引脚变高阻，电平不可控，可能残留在高电平让光耦一直通着）。
