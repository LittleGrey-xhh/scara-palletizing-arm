## 一、信号侧：STM32 引脚 → 各个器件

中控板底板是"排母 + 并联排针双引出"，用排针引出来接杜邦线。

| STM32 引脚 | 接到哪个器件的哪根线 | 备注 |
|---|---|---|
| **PA0** | 大臂舵机 信号（**橙/黄/白**） | TIM2_CH1，50Hz |
| **PA1** | 小臂舵机 信号 | TIM2_CH2，50Hz |
| **PB8** | 腕转舵机 信号 | TIM4_CH3，50Hz |
| **PB6** | 夹爪舵机 信号 | TIM4_CH1，50Hz（★ 前提：OLED 没焊） |
| **PA8** | 驱动器 **PUL−** | TIM1_CH1，脉冲 |
| **PB9** | 驱动器 **DIR−** | 方向 |
| **PB14** | 驱动器 **ENA−** | 使能，低有效 |
| **3.3V** | 驱动器 **PUL+ / DIR+ / ENA+** | ★ 共阳，三根并到一起接 3.3V |
| **PB12** | 限位 黑线 **串 1k 电阻** | 内部上拉，下降沿 |
| **PA9** | USB 转串口模块 **RX** | 交叉接 |
| **PA10** | USB 转串口模块 **TX** | 交叉接 |
| **PB4** | 编码器 白线（A）**串 1k** | 可选，TIM3_CH1 |
| **PB5** | 编码器 绿线（B）**串 1k** | 可选，TIM3_CH2 |
| **GND** | 所有器件的 GND | ★ 见第三节 |

**★ 3.3V 从哪里取：** 中控板排针上引出的 3.3V，或者从 STM32 板上的 3.3V 排针。**不要从降压模块的 5V 取**（共阳必须 3.3V，接 5V 光耦会半导通）。如果板上 3.3V 不好找，直接用一个 AMS1117 单独稳压也行。

## 二、电源侧

```
24V 5A 适配器
  │
  ├─(1)─→ 驱动器 VCC / GND          ← 并 470μF/50V
  │
  ├─(2)─→ 限位传感器 棕线 / 蓝线     ← ★ 棕线要 10~30V，不能接 5V
  │
  └─(3)─→ 降压模块 IN+ / IN−
             │
             ├─ CH1 调到 6.0V ─→ 四个舵机的 红线（并 2200μF/16V）
             └─ CH2 留 5.0V   ─→ 编码器 Vcc（选了编码器才接）

STM32 自己用 USB 供电，不从上面取电
```

| 编号 | 从哪 | 到哪 | 线径建议 |
|---|---|---|---|
| (1) | 24V+ | 驱动器 VCC | 20AWG 以上 |
| (1) | 24V− | 驱动器 GND | 20AWG |
| (2) | 24V+ | 限位 棕 | 任意 |
| (2) | 24V− | 限位 蓝 | 任意 |
| (3) | 24V+ / 24V− | 降压模块 IN+ / IN− | 20AWG |
| CH1 | 降压 CH1+ | 四个舵机 红线 | **18AWG，粗一点** |
| CH1 | 降压 CH1− | 四个舵机 棕/黑线 | **18AWG** |

**为什么舵机线要粗：** 四舵机同时动作 1.2A，细线压降几百毫伏，舵机扭矩直接掉。

## 三、★ 共地：只在一个点连

所有 GND 必须**星型汇聚到 24V 电源的负极**，不要串成一条链。

```
                    ┌── 驱动器 GND
                    │
                    ├── 降压模块 IN−
                    │
24V 负极 ───────────┼── 限位 蓝线
                    │
                    ├── 降压 CH1−  → 舵机 GND
                    │
                    └── STM32 GND（USB 的地）
```

**错的做法：**

```
24V− → 驱动器− → 降压− → 舵机− → STM32 GND   ← 串成一条链
```

这样舵机的大电流会流过中间那段线，在 STM32 的地上产生几百毫伏的压差 → **串口乱码、编码器丢脉冲、ADC 跳动**。

**判断有没有接错：** 用万用表量 STM32 的 GND 和 24V 负极之间，电压应该 **< 10mV**。超过 50mV 就是有共模电流在流。

### 3.1 具体怎么接（三根线汇到一个点）

降压模块输出端通常只有两个螺丝孔，要接三根线：

```
端子 CH1+  ← 只接一根：舵机 红线

端子 CH1−  ← 塞两根：
              ① 舵机 棕/黑线
              ② 一根杜邦线 → STM32 的 GND
```

**操作：** 把舵机地线和杜邦线**剥皮后绞在一起**，一起塞进 CH1− 的螺丝孔拧紧。

**★ 三个注意：**

1. **杜邦线从降压模块端子出，不从舵机线上"搭桥"。** 如果从舵机线中间剥皮搭一根，那个接点电阻会让 STM32 的参考地跟着舵机电流波动。
2. **杜邦线要短**，10cm 以内最好。长了就是天线，会捡干扰。
3. **STM32 那头插任一 GND 排针**（板上几个 GND 是内部连通的，随便哪个都行）。

**★ 为什么不能从 STM32 的 GND 往舵机方向接：** 那样舵机的 1～2A 电流要流过 STM32 板上的细铜箔（几十毫欧），地电位被抬高几十毫伏到几百毫伏，串口立刻乱码、ADC 跳动。

## 三之二、★ 电容怎么接（电解电容接反会炸）

### 3.2.1 先认极性

```
       ┌──────────────┐
       │   ▓▓▓▓▓▓▓▓   │  ← 灰色/白色条纹这一侧 = 负极（-）
       │              │
       │   2200μF     │
       │    16V       │
       │              │
       └──┬───────┬───┘
       长脚      短脚
        +         -
```

**三个判断方法，任选一个：**

| 方法 | 正极 | 负极 |
|---|---|---|
| **腿长** | **长的** | **短的** |
| **外壳条纹** | 没有条纹的那侧 | **有条纹（印着 −）的那侧** |
| 顶部防爆槽 | 通常两侧都有，看不出极性 | |

**★ 新电容腿长的一定是正极。** 剪过腿的要靠外壳条纹认。

### 3.2.2 ★★ 接反的后果：会炸

电解电容内部是卷绕的铝箔 + 电解液。反接时：

```
极性反了 → 内部氧化膜被击穿 → 电解液气化 → 内压升高
→ 顶部防爆槽裂开 → "啪"一声，喷出电解液和纸屑
```

**470μF/50V 炸起来声音像小鞭炮，会喷一手黏糊糊的电解液（有腐蚀性）。**

**所以接之前必须用万用表确认一遍，或者拍照发我看。**

### 3.2.3 两个电容分别接哪

| 电容 | 规格 | 接在哪 | 作用 |
|---|---|---|---|
| **470μF** | **50V** | **驱动器 VCC ↔ GND** | 步进电机换相时电流突变，就近补电 |
| **2200μF** | **16V** | **降压 CH1 输出 ↔ GND** | 舵机堵转瞬间补电流 |

**接法（并联，不是串联）：**

```
       驱动器 VCC (+) ──┬──────── 驱动器
                        │
                     电容 +
                        │
                     电容 −
                        │
       驱动器 GND (−) ──┴────────
```

**两个电容的正极各接各的正极，负极各接各的负极，都跟负载并联。**

### 3.2.4 ★★ 耐压值千万不能搞混

```
470μF / 50V   → 接 24V 母线，50 > 24，安全
2200μF / 16V  → 接 6V 舵机电源，16 > 6，安全
```

**如果 2200μF/16V 接到 24V 母线上 → 16V < 24V → 几秒内鼓包爆炸。**

**接之前看一眼外壳上印的电压，对号入座。**

### 3.2.5 电容能救什么、救不了什么

**能救：** 削掉电流尖峰，让母线电压不那么抖。

**救不了持续堵转。** 算一下就明白：

```
2200μF 允许压降 0.5V：
  能放出的电荷 Q = C × ΔU = 2200μF × 0.5V = 1.1mC
  如果堵转 2.5A 持续：1.1mC ÷ 2.5A = 0.44 毫秒

  也就是说电容只能撑 0.44 毫秒，2.5A 堵转 1 秒都撑不住
```

**所以电容是"削峰"，不是"供电"。真正的解法是别让它堵转。**

### 3.2.6 第一次接电容上电

**空电容上电瞬间相当于短路**，会有很大的充电浪涌：

```
24V 给 470μF 充电，能量 = 0.5 × 470μF × 24² = 0.135 焦耳
```

量不大，24V 5A 适配器能扛住。**但第一次上电注意听有没有"啪"或闻到焦味**，有就立刻拔。

**★ 千万不要带电插拔电容。** 断电 → 接好 → 检查极性 → 上电。

外壳右侧 12 个孔，**从上到下**：

| 位置 | 丝印 | 接什么 |
|---|---|---|
| 1 | `ENA−` | PB14 |
| 2 | `ENA+` | 3.3V |
| 3 | `DIR−` | PB9 |
| 4 | `DIR+` | 3.3V |
| 5 | `PUL−` | PA8 |

## 五、舵机插头（JR/FUTABA 通用）

```
     ┌───────────────┐
     │  棕/黑  红  橙 │
     │    │    │   │  │
     │   GND  6V  PWM │
     └───────────────┘
```

| 线色 | 接到 |
|---|---|
| **棕 / 黑**（最外侧） | 降压 CH1− / GND |
| **红**（中间） | 降压 CH1+ = **6.0V** |
| **橙 / 黄 / 白**（信号） | STM32 的 PWM 引脚 |

**★ 红线在中间，插反会烧。** 插头有防呆凸起，但杜邦线自己压的时候容易搞错，接之前用万用表量一遍。

## 六、限位传感器（RIKO SN04-N）

| 线色 | 接到 |
|---|---|
| **棕** | 24V 正（★ 10～30V，不能接 5V） |
| **蓝** | 24V 负 / GND |
| **黑** | **串 1k 电阻** → PB12 |

**为什么串 1k：** 万一这颗内部带上拉到电源正，输出高电平时就是 24V，直接进 IO 会烧。串了之后即使 24V 灌进来，电流也只有 (24−3.3−0.7)/1000 ≈ 20mA，IO 的内部钳位二极管能扛住。

**检测距离：** 对铁 4mm，对铝只有 2.4～2.8mm。触发体要用**铁**螺丝。

| 线色 | 接到 |
|---|---|

## 八、上电顺序（★ 严格按这个来）

```
① 什么都不接，只把 24V 接到降压模块 IN+/IN−
   量：CH1 输出 6.0V？CH2 输出 5.0V？

② 降压调好，接驱动器 VCC/GND，不接电机、不接 STM32
   量：驱动器 PWR 灯亮（绿），ALARM 不亮

③ 接 3.3V 到驱动器的 PUL+/DIR+/ENA+（三根并一起）
   量：PUL+ 对 GND = 3.3V，PUL− 对 GND 也 = 3.3V（没被拉低）

④ 接电机四根线
   用手转电机轴：拧不动 = 驱动器锁轴正常 ✔

⑤ 接 STM32（USB 供电），先不接舵机
   烧固件，发 `E 0` 松轴 → 电机能转；发 `E 1` 锁轴 → 转不动

⑥ 接舵机（红线上 6V，信号上 PA0/PA1/PB8/PB6）
   烧进去后舵机应该自动回中位，不抽、不抖

⑦ 接限位（棕 24V、蓝 GND、黑串 1k 进 PB12）
   发 `S` 看状态，用手拿铁螺丝靠近传感器，应该有反应
```

**每一步都量电压再进下一步。** 跳步的代价是烧板子。

## 十、常见故障对照

| 现象 | 最可能的原因 |
|---|---|
| 电机原地抖不转 | 电机单相接反（A+/A− 或 B+/B− 对调） |
| 电机不转，PWR 亮，ALARM 不亮 | ENA 没拉低（或 PB14 没配成输出） |
| ALARM 红灯亮 | 过流 / 电机线短路 / 电源超 42V |
| 电机能转但没力 | 驱动器电流档设太低（应在 1.0A） |
| 舵机发抖 | 电源带不动，或者信号线受干扰 |
| 舵机往一个方向猛转不停 | 脉宽超出 500～2500μs，或者信号线断了（无信号时它会乱走） |
| 串口乱码 | 波特率不对，或者没共地 |
| 限位一直触发 | 黑线没串 1k，或者传感器间隙太小 |

## 十一、★ 单个舵机通电测试（第一次上电就按这个来）

### 11.1 先纠正用词：这是**直流**，没有"零火线"

| 错误说法 | 正确说法 |
|---|---|
| 零线 / 火线 | **负极 GND（0V）** / **正极 V+（6V）** |
| 零火线 | 直流输出的**两根线** |

**"零线火线"是 220V 交流市电的说法，接错会触电。**

我们用的是：
```
24V 适配器（220V 输入，输出隔离的 24V 直流）
   ↓
降压模块（24V → 6V 直流）
   ↓
舵机
```

**降压模块输出端只有"正极"和"负极"，没有火线零线。**

**⛔ 绝对不要拿万用表去量 220V 那一侧，也不要把 220V 接到任何地方。** 24V 适配器插墙上就不用管它了。

### 11.2 必须共地（★ 会存在不共地问题）

**你的判断是对的：不共地一定会有问题。**

```
STM32 用 USB 供电 → 它的 GND = 电脑 USB 的地
降压模块用 24V 供电 → 它的 GND = 24V 适配器的负极

这两个"地"之间没有电气连接 → 电位是浮动的，可能差几十伏
```

**后果：** STM32 输出的 3.3V 是相对"USB 地"的，舵机理解的 3.3V 是相对"24V 负极"的。两边基准不一样，舵机收到的脉宽就是错的 —— 表现为抖动、乱转、或者完全不响应。

**接法：在降压模块的输出端子上做一个星型点**

```
降压 CH1+ ─────────────→ 舵机 红线（中间）
                              ↑ 6.0V

降压 CH1− ──┬──────────→ 舵机 棕/黑线
            │
            └──────────→ STM32 的 GND（任一 GND 排针）
```

**关键：接地点在降压模块端子上，不在 STM32 板上。**

如果从 STM32 的 GND 排针引出去接舵机，舵机的 1～2A 电流会流过 STM32 板上的细铜箔，地电位被抬起来，串口立刻乱码。

### 11.3 接线顺序（★ 按这个顺序，别跳）

```
① 断电状态下，先把三根线全部接好
   舵机红   → 降压 CH1+
   舵机棕黑 → 降压 CH1−  ← 同一个点也引一根到 STM32 GND
   舵机橙   → PA0

② 万用表量一遍（不通电就要量完）
   CH1+ 对 CH1−  → 应该是 6.0V（这时还没通电，量不出来是正常的，先看降压模块旋钮位置）
   ★ 断电时量"通断"，确认红线没接反、没有短路

③ 上电
   先插 24V 适配器 → 舵机应该"哒"一声，转到某个位置

④ 烧固件，上电
   舵机应该转到中位并停住，不抖不响
```

### 11.4 会看到什么

| 现象 | 说明 | 该怎么办 |
|---|---|---|
| 上电"哒"一声，转到某位置停住 | 正常，它在找中位 | 继续 |
| 转到中位后静止不动 | 完美 | 发命令测试行程 |
| 一直抖 | 信号线干扰 / 共地不良 / 电源不稳 | 检查共地，缩短信号线 |
| 往一个方向猛转不停 | 脉宽超范围或信号线断 | 立刻断电 |
| 完全不响应 | 信号线没接对，或 3.3V 电平不被识别 | 见 11.6 |
| 外壳迅速发烫 | 顶死了 | 立刻断电 |

### 11.5 串口测行程（接好之后）

```
K 0 1500      → 中位
K 0 1200      → 往一边转约 27°
K 0 1800      → 往另一边转约 27°
K 0 1000      → 转到 45° 位置
K 0 2000      → 转到 135° 位置
```

**先不要发 500 和 2500**，那是理论极限，舵机可能已经顶死。等标定出安全边界再试。

每发一条，看舵机转到新位置后**是否安静**。有嗡嗡声就立刻发 `K 0 1500` 回中位。

### 11.6 如果完全不响应：3.3V 信号可能不够

舵机内部按 5V 逻辑设计，高电平阈值大概 2.0～3.5V。**大部分 MG996R 吃 3.3V 没问题，但个别批次会不认。**

**验证办法：** 拿一根杜邦线，把信号线临时接到 5V（降压 CH2 的 5V），舵机应该立刻转到极限位置（因为 5V 直流相当于超长脉宽）。

**如果接 5V 有反应、接 3.3V 没反应 → 就是电平不够。**

**解决办法（按简单程度）：**

| 方案 | 做法 | 成本 |
|---|---|---|
| **A. 串一个上拉电阻** | 信号线到 5V 之间接 4.7k，MCU 侧仍是 3.3V | 几毛 |
| B. 加 74HCT245 | 3.3V → 5V 电平转换 | 3 元，要焊 |
| C. 换 STM32 的 5V 容忍脚 | **不行**，F103 的 IO 不是 5V 容忍的 | — |

**★ 方案 A 的原理：** STM32 输出低电平时把线拉到 0V（能灌 20mA，压得住上拉）；输出高电平时线被 4.7k 拉到 5V。这样舵机收到的是 0V / 5V 的干净信号，而 STM32 不用承受 5V（因为 4.7k 限制了电流到 (5−3.3)/4700 = 0.36mA，IO 的内部钳位二极管能吃下）。

### 11.7 测完一个再测下一个

**一次只接一个舵机。** 四个一起接，出问题分不清是哪个。

顺序建议：**先夹爪（负载最轻、坏了也不心疼）→ 再腕转 → 再小臂 → 最后大臂**。

## 十二、★ 停机后会不会掉

**主人的判断是对的：不会掉，但会松。**

### 12.1 舵机停 PWM 后会怎样

我们的臂**全部在水平面内**，重力垂直向下：

```
舵机停 PWM → 失去保持力矩
  → 臂可以在水平面内被外力推着转
  → 但不会"掉下来"，因为没有垂直方向的自由度
```

**注意：这是水平 SCARA 的特权。** 垂直关节型的机械臂（像 WS-04 如果有俯仰轴）停 PWM 会直接被重力压下来砸桌子。

### 12.2 步进停 PWM 后会怎样

**T8 丝杆是自锁的**，实测你也验证了（压都压不动，只能转丝杆）。

原理：
```
螺旋升角 λ = arctan(导程 / (π × 中径))
           = arctan(4 / (π × 8))
           = 9.05°

摩擦角 φ = arctan(μ)，钢-青铜 μ ≈ 0.1~0.15 → φ ≈ 5.7~8.5°

λ (9.05°) 略大于 φ (8.5°) → 理论上临界，可能慢速下滑
```

**但你的滑台实测压不动**，说明实际摩擦（滑块预紧 + 丝杆螺母阻尼）比理论值大，**是自锁的**。

**★ 但要留意一个长期风险：** 丝杆和螺母磨损后摩擦会下降，可能从"自锁"变成"缓慢下滑"。判断办法：断电放置 24 小时，看刻度有没有变化。

### 12.3 所以断电是安全的，但有两个提醒

| 提醒 | 原因 |
|---|---|
| 断电前把臂收到"重心靠近立柱"的位置 | 万一被人碰，力臂短不容易撞坏 |
| 别在断电状态下硬掰 | 舵机虽然不锁，但齿轮在反向驱动，会加速磨损 |

**真正的风险不是"掉"，是"被人碰到后位置变了，下次上电以为还在原地"** —— 所以每次上电必须重新回零 + 回中位。
