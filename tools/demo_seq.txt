# 平面搬运 V1：抓取点 (100,0) → 放置点 (200,0)
#
# ★★ 11-23 夹爪倾斜补偿：下垂让夹爪朝回转中心倾斜，越往外偏得越多，
#   所以放置点指令要比目标值大。
#   实测数据（标定板 0 刻度对齐 M 80 时的板读数）：
#       指令 80  → 板 0cm       指令 198 → 板 10.0cm
#       指令 100 → 板 1.8cm     指令 222 → 板 11.5cm
#       指令 137 → 板 5.0cm     指令 225 → 板 12.0cm
#   抓取点 M 100 在板 1.8cm，要走满 100mm 落点需到板 11.8cm
#   → 取 M 224（预期落 11.8cm，位移 100mm，误差 0.3mm）
#   ★ 换算系数随半径递减（50~100mm 段 0.82、100~120mm 段 0.74），是非线性的，
#   不要拿一个固定比例套全行程
#   ★ 这个补偿只沿 X 轴成立（偏移方向朝回转中心），走 Y 或斜线会失效
#
# ★★ 11-23 Z 值重定（比补偿公式更关键）：下垂把末端拉低十几到二十几毫米，
#   所以"看起来该多高"和"实际多高"差一大截。实测触地点（纸巾底部刚碰台面）：
#       M 100 处 Z≈16      M 158 处 Z=25      M 224 处 Z=35
#   → 每往外 66mm 半径，触地 Z 抬高 10mm（下垂随半径线性增长，斜率 0.15）
#   ★★ 采用值统一为「触地点 − 1」，即压下 1mm：
#       抓取 Z 15（M100 触地 16 − 1）      放置 Z 34（M224 触地 35 − 1）
#   ★★★ 为什么必须轻压 1mm 而不是完全悬空：
#       压 0mm（纯悬空）→ 张开瞬间物体自由落体，实测 Z 25 时纸巾姿态翻掉；
#       压 1~2mm        → 接触面摩擦帮它定型，Z 24 实测姿态稳定；
#       压 5mm 以上     → 地面反力开始抵消下垂，补偿量偏大（量化待方块复测）
#   → 甜点区是「轻压 1~2mm」。★ 堆叠测试时更要轻压，否则物体叠上去会滑
#   ★ 这些 Z 值只对当前这个纸巾包（约 60mm 高）有效，换木方块必须重测触地点
#
# ★★ 等待时间是按实际耗时算的，别随手改小：
#   Z 每走 45~50mm 要 4.5~5 秒（10mm/s）→ 给 !6
#   H 回零 = BACKOFF 0.5s + SEEK(深度不定) + RETREAT 0.3s → 给 !8，且必须在所有 Z 命令之前
#     因为 s_homed 只在 HOME DONE 那一刻才置 1，早发 Z 会 ERR 5
#   HM 是 3 秒斜坡 → 给 !4
#   M 走 65mm 约 1.5 秒、C 两段式约 1 秒 → !3 够
#
# ★ 起点固定：串口一打开 MCU 就复位（CH340 的 DTR/RTS 接 NRST），s_homed=0，
#   所以第一条必须是 H，不能省。
